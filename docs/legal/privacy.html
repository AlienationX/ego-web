一、主体信息

欢迎使用 [本我壁纸]（以下简称“本应用”）。本应用由舒丽（以下简称"我们"）开发和运营。我们高度重视您的隐私与个人信息保护，并承诺严格遵守相关法律法规。本协议旨在说明我们如何收集、使用、存储、共享及保护您的个人信息。请在使用本应用前仔细阅读并充分理解本协议。如有疑问，请通过文末联系方式与我们联系。

二、信息收集与使用

2.1 注册信息

若您选择注册账号，我们可能收集您的电子邮箱地址、第三方账号授权信息（如华为账号、微信账号标识），以便提供个性化服务、数据同步及账户管理。

2.2 设备与使用数据

为保障应用正常运行及优化性能体验，我们可能收集以下信息：

  • 设备信息：设备型号、操作系统版本、唯一设备标识符（如 IMEI、Android ID、OAID 移动智能终端补充设备标识）、IP 地址、设备 MAC 地址、网络类型及状态等。
  • 软件安装列表：为提供便捷登录（如微信快捷登录）及社交分享功能，或在相关合规广告场景中提升广告反作弊与展示效果，我们或集成的第三方广告 SDK 可能在必要时获取应用安装列表。
  • 使用行为：壁纸浏览、搜索、下载、收藏记录，以及应用内操作日志等。
  • 位置信息（若授权）：基于 IP 或网络的大致粗略位置信息，用于提供本地化服务推荐及广告合规归因。
  • 传感器信息：加速度传感器、陀螺仪、方向传感器等设备内置传感器，用于优化应用性能、实现特定交互功能（如设备方向感知、壁纸重力感应效果），以及广告投放和效果反作弊。

我们收集设备标识信息（包括 OAID）的目的、方式和范围如下：

  • 收集目的：用于设备唯一性识别、防止欺诈行为、优化用户体验、提供个性化服务、统计分析。
  • 收集方式：通过系统官方 API 在用户授权后自动收集，不会在后台静默收集。
  • 收集范围：仅收集必要的设备标识信息，不收集设备中的其他无关敏感数据。
  • OAID 说明：OAID 是移动智能终端补充设备标识，用于在不获取用户隐私信息的情况下进行匿名设备识别，符合相关国家监管及平台规范要求。

2.3 应用权限使用说明

为提供完整的壁纸体验，我们可能在您使用特定功能时请求以下系统权限：

  • 存储权限 / 相册权限（WRITE_EXTERNAL_STORAGE / READ_MEDIA_IMAGES）：用于保存下载的高清壁纸到本地相册，以及创建本地缓存提升浏览速度。我们仅在您主动点击下载壁纸或上传反馈图片时请求此权限。
  • 相机权限（CAMERA）：用于拍摄照片作为意见反馈上传。仅在您主动点击反馈并选择拍照时请求。
  • 系统设置权限（WRITE_SETTINGS）：用于在支持的设备上一键设置系统手机壁纸。
  • 网络访问权限（INTERNET / ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE）：用于加载网络壁纸数据、检查更新及同步用户信息。

我们承诺仅在您触发对应业务功能时动态请求上述权限，您可以随时在系统设置中撤回或关闭权限，关闭权限不会影响其他基础功能的使用。

在法律法规强制要求或司法行政程序需要的情况下，我们可能依据法定程序向相关部门披露必要数据。如发生合并、收购或资产重组，您的个人信息可能作为业务资产转移，我们将在转移前告知您接收方的名称和联系方式。

四、用户权利与个人信息管理

4.1 访问、更正与删除

您可随时在应用内【我的】页面查看或修改您的个人资料，或通过【我的-设置-注销账号】申请注销账户并删除所有关联数据。

4.2 撤回同意

您可以通过手机系统设置随时关闭应用授权（如相册存储、相机等），或在应用内反馈联系我们撤回个人信息处理授权。

五、数据安全与保护措施

我们采用行业标准的安全技术（包括 HTTPS/TLS 传输加密、哈希脱敏、访问权限隔离等）来保护您的个人信息安全，防止未经授权的访问、泄露或篡改。

六、儿童隐私保护

本应用主要面向成年用户。若您为未满 14 周岁的未成年人，请在法定监护人的陪同与指导下阅读并使用本应用。若我们在知情情况下发现意外收集了未成年人信息，将依法及时予以删除。

七、政策更新与通知

我们可能会适时对本协议进行修订。当条款发生重大变更时，我们将在应用启动时通过弹窗、通知或页面显著位置向您提示，您在变更生效后继续使用本应用即表示同意更新后的隐私协议。
